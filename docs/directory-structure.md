# ディレクトリ構成

rrmapのCLI/UIが操作するタスクファイルは、プロジェクトルート直下の `.rrmap/` に配置する。

```
.rrmap/
  tasks/       # タスクファイル（1タスク = 1 Markdownファイル。フォーマットは task-format.md 参照）
  milestones/  # マイルストーンファイル（1マイルストーン = 1 Markdownファイル。フォーマットは milestone-format.md 参照）
```

## Knowledgeドキュメント

Knowledgeドキュメントは、rrmapのCLI/UIからは直接操作しない（Skillが判断して書き込む程度）。人間が普段から見る場所に置きたいので、`.rrmap/`ではなく `docs/knowledge/` に配置する。

フォーマットも自由なMarkdown。テンプレートは強制しない。

ADRやユーザー向けドキュメントなど、既に役割が確立しているドキュメントも同様にrrmapの管理対象外。既存の置き場所・仕組みをそのまま使う。

## パスの変更

`.rrmap/`はデフォルトの固定パスであり、設定ファイルでベースパスを上書きできるようにする（モノレポで複数箇所に持たせる用途までは想定しない、単一パスの差し替えのみ）。

設定ファイルのフォーマット・置き場所は未定。
