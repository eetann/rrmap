status: done

ピークを開くとタイトルにフォーカスが当たる。そのため中身を変えていなくても、閉じるときの onBlur で PATCH が飛んでいた。ファイルが書き直されると frontmatter が正規化され、マイルストーンには `hidden: false` が書き足されて差分が出る。

対処として、値が変わっていないときは PATCH を送らないようにした。タイトル・本文・ステータス・マイルストーン選択のすべてが対象。

ハマりどころ: Escape で閉じた場合はアンマウントが先に起きて blur が発火しないため、再現しない。×ボタンや別の要素をクリックして閉じたときだけ起きる。
